# Case records

Reports from adopting a practice in an environment other than the one it came from. One file per
report, named for the entry it concerns.

Case records are kept **separate from the practices** on purpose. Several incompatible reports can
all be worth preserving even when none of them yet justifies changing a recommendation, and a
practice that quietly absorbed every report would lose the disagreement that makes it useful.

A record here is not an endorsement and not a correction. It is an observation, filed.

See [CONTRIBUTING.md](../CONTRIBUTING.md) for the fields.
